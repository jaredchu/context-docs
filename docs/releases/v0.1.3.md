# v0.1.3 — experimental

This release bundles **context-docs 0.1.3** and **adopt-context-docs 0.1.5**.
The Markdown standard remains 0.1.0.

## Changes

- Include the Claude Code support merged in [PR #1](https://github.com/jaredchu/context-docs/pull/1):
  installation guidance, adoption in the instruction file a client loads, tighter
  evidence and decision attribution, and native evaluation tooling/results.
- Package an optional Python 3.9+ JSONL helper for historical event capture and
  investigation, including projects without Git or with infrequent commits.
  Per-session files provide rotation; retention and cleanup remain manual.
- Preserve existing adopters' dates, paths, maintenance rules and history.
  Explicit enable/disable requests merge settings; repeat setup and audits write
  no events. Failed capture retains a concise Markdown note explaining the gap.
- Add helper, portable-package and evaluation-boundary regression checks to CI.

## Upgrade

Install both complete skill folders together using the
[installation instructions](../../README.md#install-in-codex), or the
[Claude instructions](../../README.md#install-in-claude-code). Review local
customizations before replacing existing copies.

Upgrades leave logging off unless a project already opted in. Ordinary Markdown
maintenance has no runtime dependency. Follow the
[journal guide](../../skills/context-docs/references/event-journal.md) to enable
logging explicitly. Disabling retains all history. There is no background capture.

## Validation and limits

The local CI-equivalent release check passed all 88 regression tests, core and
quality self-tests, Claude smoke-runner controls, adoption grader controls,
packaging/link/version checks and regeneration of the four checked reports.
These mechanical checks are separate from model evaluations.

The [first Linux CI run](https://github.com/jaredchu/context-docs/actions/runs/36413883433)
then exposed generated Python bytecode being copied into a Claude text fixture.
The fixture copy and package manifest now exclude bytecode while retaining helper
sources. The added regression brings the suite to 89 tests; no skill behavior or
frozen model result changed in this harness repair.

Native journal evidence includes a [12-session format comparison](../../evals/results/2026-09-28-native-journal/README.md)
and [31 lifecycle/follow-up sessions](../../evals/results/2026-09-28-journal-integration/README.md)
across Codex and Claude. Codex passed the functional lifecycle; Claude's initial
setup failures remain recorded, followed by functional passes with explicit
native invocation and retained semantic/execution limitations. Both clients passed
the focused [capture-gap follow-up](../../evals/results/2026-09-28-journal-gap/README.md).
A final clarification about unconfirmed writes received static review only.

This is an experimental release for supervised use. General reliability,
automatic selection, and a recording-cost advantage remain unestablished.
The comparisons do not establish that JSONL is necessary when Markdown/Git already
preserves the needed history. Earlier failures and frozen candidate evidence remain
available; this release does not rescore them.

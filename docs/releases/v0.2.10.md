# v0.2.10 experimental prerelease

This bundle includes **Context Docs 0.2.10** and **Adopt Context Docs 0.1.17**.
Previous bundle: [v0.2.9](v0.2.9.md).

## Changes

- Add a [shared Markdown ticket lifecycle](../../skills/context-docs/references/tickets.md)
  for projects that use tickets or request them. The guidance covers opening,
  maintaining, filing and reopening tickets through the existing Context Docs rule.
- File completed tickets in `done/` when requested or when the project uses
  that convention. Check recorded completion and update editable references.
- When reopening the same work, restore its active link, update the next
  action and preserve the earlier outcome and evidence as history.

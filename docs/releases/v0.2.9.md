# v0.2.9 experimental prerelease

The [experimental prerelease](https://github.com/jaredchu/context-docs/releases/tag/v0.2.9)
was published on 2026-11-25 from `3337eb9`. It bundles **Context Docs 0.2.9**
and **Adopt Context Docs 0.1.17**. Previous bundle: [v0.2.8](v0.2.8.md).

## Changes

- Retire optional JSONL event capture and the auto preference from the core
  and adoption skills, setup instructions and website guide.
- Keep current context in Markdown. Preserve existing journal files and
  historical evaluations. The [upgrade guide](../getting-started.md#older-jsonl-journal-setups)
  describes clean package replacement and cleanup of obsolete settings.

## Candidate checks

The [removal source](https://github.com/jaredchu/context-docs/commit/45557cf217393c130b82239f3f0f9861b25f4840)
passed static checks, 229 automated tests in a clean checkout, a site build and
independent follow-up review. A separate offline, project-scoped upgrade used
`skills 1.7.4` in a disposable project. Both the Codex and Claude Code layouts
started with v0.2.8. After retaining the old package folders as backups and
installing the candidate into clean folders, all 13 installed skill files in
each layout matched the candidate bytes. The retired guide and both helpers
were absent from the active folders. Synthetic JSONL, the Markdown entry point,
and the fixture project's existing instruction files stayed byte-identical.

The check covers package contents and the documented clean replacement workflow.
An in-place overwrite, legacy instruction interpretation and automatic
discovery by a running agent remain untested by this upgrade check.

## Publication and upgrade verification

Both public tag archives and one isolated `skills 1.7.4` install from the
public default branch matched all 13 verified package files. The install's
original telemetry request returned HTTP 200, and existing installed skills
were preserved.

After five paired checks over about 100 seconds, the [context-docs](https://www.skills.sh/jaredchu/context-docs/context-docs)
listing still matched v0.2.8. The [adopt-context-docs](https://www.skills.sh/jaredchu/context-docs/adopt-context-docs) listing
matched the identical v0.2.7 and v0.2.8 text. Both comparisons included collapsed content.
The refresh result covers the observed interval.

The automatic [website deployment](../../site/README.md#latest-deployment)
verified the updated install pins from `9008ac6`.

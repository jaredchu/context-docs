## Limits and preservation

This is a guided, author-scored writing smoke with explicit candidate paths and
an explicit request to clarify prose. The two cases share a session per client.
It does not test implicit discovery, automatic everyday application, fresh setup,
cross-session continuity or the full evaluation suite. It does not demonstrate
better comprehension, human reading speed, general reliability or ASD-STE100
compliance. The earlier tiny comparison remains separate: both original and
rewritten notes scored 12/12, with no demonstrated comprehension gain.

All 16 source candidate files and 32 installed package files remain byte/mode
equal to the pre-run inventory. Existing setups, saved studies and prior private
evidence are preserved. Only new synthetic evidence, current context, changelog
validation and a new journal event are added or updated in this task. Git metadata
and routine global client bookkeeping are excluded; no global-state equality is
claimed. No skill edits, installed upgrade, release or deployment is part of this smoke.

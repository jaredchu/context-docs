# Concision experiment plan

Frozen before authoring the new fixtures on September 27, 2026.

Compare the published v0.1.0 entry point with `candidate-SKILL.md`. Package both
with the same v0.1.0 references, assets and UI metadata. The candidate shortens
the workflow and explicitly discourages repeated generic caveats and speculative
initialization inventories. No candidate tuning after scored runs begin.

Use three new synthetic projects with at least 500 initial Markdown words each:
dispersed release guidance with conflicting authority, initialization from mature
existing documentation, and three maintenance passes over changing configuration
with existing uncommitted work. Author fixtures after freezing the candidate.
These are author-created development cases, not independently held-out projects.

Run two attempts per project and variant: 12 complete trials, 20 agent sessions.
Use the same pinned Harbor/Codex/model/effort as the earlier 48-trial experiment.
Alternate submitted variant order, use fresh containers, and keep concurrency at
two. Run reference and no-op controls first. Preserve errors without replacement.
Capture actual files immediately before every maintenance pass.

Primary gate: all mechanical and semantic preservation criteria pass, with no
candidate regression relative to the original. Inspect scope and Git operations.
Secondary outcome: candidate median net Markdown growth is lower in at least two
of the three tasks, with no task adding over 50 more words than the original
median. Final no-change passes should leave Markdown unchanged. Report total
and per-task word growth, time and tokens; do not treat length alone as quality.

Passing supports adoption for further use, not a general superiority claim.
Failure leaves the published skill unchanged and the candidate/results available
for review. Semantic review is by the authoring assistant with explicit evidence;
condition-hidden packets reduce labeling cues but do not make review independent.
The earlier 48-trial result is preserved, not silently regraded.

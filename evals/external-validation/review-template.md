# Artifact review — copy per artifact

Review each neutral artifact ID before comparing methods. Use the supplied full
shared source corpus, task, scope and evaluator ledger. Ask the coordinator for
missing evidence; do not substitute current upstream state for pinned history.
No model subscription, Python installation or upstream code execution is needed.
Request the packet and submit initial judgments using the
[issue/PR route](README.md#two-ways-to-contribute) before receiving the mapping.
Other submissions are public; record exposure and avoid reading them first.

## Disclosure

- Reviewer/public identifier; date; human/AI assistance and actual model if used:
- Relationship to protocol authors; involvement in selection, setup or execution:
- Skill, study results, condition labels or other reviews previously seen:
- Packet received: artifact ID, source/manifest revision, task, ledger, documents,
  final response and diff; missing material or access limits:
- Treatment guessed during review, why and when (or unknown):
- Evidence consulted outside the shared corpus, purpose and limits (or none):

| Current guidance consistent; conflicts and unknowns represented accurately | | |

| Permitted edits and source integrity (only what supplied evidence verifies) | | |

For each finding: quote the artifact's exact claim/location; cite pinned source
revision/path/lines; explain support, contradiction or missing evidence. Distinguish
an unsupported assertion from a disproved one and a wording caution from a material
failure. Check the full supplied corpus, not only files cited by the artifact.
Raw evidence surviving in the repository alone does not prove a required item was
retained in usable docs. Record rubric errors now; append repairs to the existing
trail without overwriting frozen scores. Read/tool traces follow initial scoring.

- Material failures, individually (do not average them into a pass):

- Useful content or justified uncertainty retained:
- Initial overall assessment and unresolved questions; record date before unmasking:

## After unmasking — append, never replace initial judgments

- Disclosed mapping and date; any masking edits or accidental exposure:
- Disagreement/resolution: finding ID, source evidence, original positions,
  integrator decision, remaining uncertainty and any reviewer follow-up:
- Evaluator error/repair: old/new criterion, evidence, timing and impact. Preserve
  frozen scores; a supplemental interpretation is separately labeled.
- Conclusion limited to these artifacts; no claim of reader benefit or general
  method superiority/equivalence. For old HTTPX/ripgrep outputs, label this a
  supplemental review and link the unchanged original assessment.

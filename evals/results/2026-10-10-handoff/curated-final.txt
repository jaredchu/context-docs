**What changed**
- **`queue_cli.py`:**
  - `format_records(records, limit=None)` now keeps only the first N records, in the order they arrived. I didn't use the sorting from the October 2 design because Mira's October 4 reply replaced it.

  - keeping input order when a limit is set
  - `--limit 0` printing nothing
  - a limit larger than the file printing every record
  - the input list not being changed
  - CLI default output unchanged
  - the `--limit` flag on the CLI
  - the source file unchanged after a run
  - exit code 2 for `-1` and `abc`

  1. November 14, 2026 · Newest

    From project source to usable documentation: three public cases

    Exploratory, agent-only · Three pinned public projects · 21 sessions

    What was tested

    The original documentation of three pinned public projects was compared with documentation an AI agent wrote using ordinary Markdown or Context Docs. A fresh agent then answered eight questions per project from the saved documents only.

    Observed result

    On the sampled supported questions, both writing conditions yielded more fully correct, validly cited answers than the original docs. Context Docs did not outperform ordinary Markdown on that metric.

    Qualifications

    AI assessments with AI-prepared keys, one writer per condition and case, and partial blinding. Two key/question disputes remain unresolved, and pass-2 document-audit flags are unreconciled. Human effort, newcomer understanding and ongoing maintenance were not measured.

  2. November 13, 2026

    Context Docs and ordinary Markdown: a small continuation experiment

    Exploratory, agent-only · Three synthetic projects · 12 subject sessions

    What was tested

    Context Docs was compared with competent ordinary Markdown maintenance. In each condition a writer saved facts from a work conversation and a later rule change; a separate fresh receiver read the saved project and proposed the next action and check.

    Observed result

    Recovery scores favored ordinary Markdown in two cases and tied in the third. All six proposed continuations scored 2/2, the ceiling of that rubric.

    Qualifications

    One Context Docs receiver lacked required captured read evidence, so its pair is excluded and there is no clean three-pair average. An earlier partial run pointed the other way in one case. The results show neither a Context Docs advantage nor general equivalence or disadvantage; newcomer adoption effort was not measured.

HOW TO READ THESE

Narrow observations, not a ranking.

Both studies are maintainer-run and agent-only, with one selected model and three cases each: synthetic projects in one, pinned public projects in the other. Comparisons with competent ordinary Markdown are quality diagnostics. They do not form a general ranking of methods, and neither study establishes a Context Docs advantage.

Neither study measured newcomer setup effort, human effort or the convenience of having documentation conventions ready. Each report retains its exclusions, unresolved disputes, earlier attempts and interpretation limits. Read the full report before relying on a number.

This website links to public evidence in the GitHub repository; it does not copy evaluation files, study logs or project context. Each evidence extract is a maintainer-prepared derivative. Private controller logs, account settings and operator records are not public evidence.

Earlier studies, with their own methods and limits, are listed in the evidence overview.
